你做完了模型，摆好了物件，材质也调得差不多了。渲染出来一看，东西都在，比例也对，但整张图就是“干”——像一张产品目录页，不像一个有情绪的场景。你换了个HDRI，加了两盏灯，调了曝光，氛围感没出来，反而更平了。

问题不在灯的数量，也不在渲染器。氛围感是灯光和构图合谋的结果，而你的灯光和构图，大概率各干各的。

第一件事：你的光没有“时间”，所以场景没有情绪。

新手打光，习惯是“把场景照亮”。主光、补光、轮廓光按教程摆好，参数调到能看清所有细节，完事。这样打出来的光，技术上正确，但情绪上是中性的——它不表达任何时间、任何天气、任何故事。

氛围感的光，第一个要回答的问题是：这是什么时刻？ 清晨的光是低角度、偏冷、带雾的；正午的光是硬、短、高对比的；黄昏的光是暖、斜、拉长影子的；夜晚的光是局部、人造、有明确光源的。你不需要做复杂的物理天空，你只需要在打光之前，先定一个时间词。然后所有灯光参数都往这个词上靠：色温、角度、强度、阴影软硬。一个黄昏的场景，主光应该是低角度暖色，阴影长而柔，暗部带一点冷色补光。一个清晨的场景，主光是低角度冷色，整体对比低，加一点体积雾。光的情绪不来自亮度，来自它暗示的那个时刻。

第二件事：你的构图没有“入口”，观者不知道从哪看起。

氛围感的另一半在构图。很多人摆场景，习惯是把所有东西均匀地分布在画面里，每个物件都露个脸，每个角落都填满。结果观者的眼睛在画面里乱跑，跑完之后什么都没记住。

好的构图有一个视觉入口——观者的眼睛第一眼落在哪里，然后沿着什么路径移动到第二点、第三点。这个入口通常是一个高对比区域：最亮的地方、最暗的地方、颜色最饱和的地方、或者唯一有暖光的地方。你把主光打在哪里，哪里就是入口。入口不能多，一个画面只能有一个。剩下的区域按重要性递减安排细节密度和对比度。氛围感的构图，是让观者感觉“被引导着看”，而不是“自己找着看”。 一个简单的自检方法：把图缩小到手机屏幕大小，眯眼看，第一眼落在哪？如果第一眼找不到落点，构图就是散的。

第三件事：你的画面没有“空气”，所有东西都贴在同一个平面上。

这是最容易被忽略、也最能快速提升氛围感的一条。真实的场景里，空气不是透明的。它有雾、有尘、有水汽、有光晕。远处的物体比近处的物体对比度低、饱和度低、偏冷或偏背景色。这就是空气透视。

你的渲染图看起来“干”，往往是因为所有物件从近到远的对比度、饱和度、清晰度都一样。加一层体积雾，或者在后处理里做一个深度渐变，让远处的东西稍微模糊、稍微偏色、稍微降对比，画面的空间纵深立刻出来。不需要很浓的雾，只需要让空气“有重量”。另一个技巧是加一点光晕：主光方向如果有体积光穿过窗户、穿过树叶、穿过烟雾，画面会立刻从“渲染”变成“场景”。体积雾和光晕不需要复杂设置，Blender的EEVEE和Cycles都支持，花十分钟调一下，效果比换材质明显。

第四件事：你的色彩没有“统一”，每个物件都在说自己颜色的话。

氛围感的场景，色彩是统一的。不是所有东西都一个颜色，是所有颜色共享同一个色调倾向。黄昏的场景，所有颜色都蒙一层暖橙；清晨的场景，所有颜色都偏冷蓝；雨天的场景，所有颜色饱和度都压低、偏灰绿。这个统一的色调不需要在材质里一个个调，在后处理里加一个色彩平衡或者LUT就够。关键是先定色调，再调局部。如果你先调每个物件的颜色，最后再统一，你会发现有的物件怎么调都和整体不搭。正确的顺序是反过来的：先给整个画面定一个基调色，然后在这个基调下，让主角色稍微偏离一点，形成对比但不破坏统一。氛围感的色彩，是“大家都住在同一个世界里”，而不是“每个人都穿自己的衣服”。

四件事指向同一个底层逻辑：氛围感不是加出来的，是控制出来的。 控制光的时间、控制构图的入口、控制空气的厚度、控制色彩的基调。你不需要更贵的渲染器，也不需要更多的灯。你需要在按下渲染之前，先问自己四个问题：这是什么时刻？观者第一眼看哪？空气有没有重量？所有颜色是不是一家人？
